# Resumo: Introdução à Linguagem Python

## 📌 O que é Python
Python é uma linguagem de programação de alto nível, interpretada, multiplataforma e de propósito geral. Seu principal foco está na simplicidade, legibilidade e produtividade, tornando-a ideal tanto para iniciantes quanto para profissionais.

É amplamente utilizada em diversas áreas, como:
- Desenvolvimento web
- Automação de tarefas
- Ciência e análise de dados
- Inteligência artificial e Machine Learning
- Computação científica
- Educação

---

## 🕰️ Histórico
Python foi criada no final dos anos 1980 por Guido van Rossum, com o objetivo de ser uma linguagem simples e poderosa.

- Primeira versão: **Python 0.9.0 (1991)**
- Versão moderna: **Python 3.0 (2008)**
- Nome inspirado no grupo humorístico **Monty Python**

---

## 🚀 Por que usar Python?

### ✔️ Simplicidade e Legibilidade
- Sintaxe clara e próxima da linguagem humana
- Fácil aprendizado e manutenção

### ✔️ Alta Produtividade
- Menos código para resolver problemas complexos

### ✔️ Grande Comunidade
- Muitas bibliotecas e frameworks
- Documentação ampla
- Forte suporte da comunidade

### ✔️ Uso na Indústria
- Utilizada por grandes empresas como Google, Netflix, Amazon, Spotify e Meta

### ✔️ Uso Acadêmico
- Muito presente em universidades e pesquisas científicas

---

## 🧠 Principais Áreas de Aplicação

- **Automação:** scripts para tarefas repetitivas  
- **Web:** desenvolvimento com Flask e Django  
- **Ciência de Dados:** análise e visualização  
- **Machine Learning:** criação de modelos  
- **Inteligência Artificial:** NLP, visão computacional, etc

### 🔧 Instalação
- Disponível em: https://www.python.org  
- Compatível com Windows, Linux e macOS  
- Algumas distribuições Linux já possuem Python instalado

### ▶️ Execução de Código

- **Modo interativo:** execução linha por linha
